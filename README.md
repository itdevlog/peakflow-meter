# Медицинский трекер «Пикфлоуметр»

Система для ежедневного контроля здоровья ребенка (астма, бронхит). Ребенок вносит результаты замеров, родитель видит историю и графики.

## Архитектура

- Монолитное приложение на Python (FastAPI) с React-фронтендом
- База данных PostgreSQL
- Кеширование через Redis
- Асинхронная обработка задач через Celery
- Telegram-бот для быстрого добавления замеров

## Основные функции

- Учет результатов пикфлоуметрии
- Расчет зон (зеленая/желтая/красная) по возрасту, росту и лучшему результату
- Личные кабинеты для родителя и ребенка
- Напоминания о необходимости измерений
- Графики и история замеров
- Адаптивный интерфейс с приоритетом на мобильные устройства
