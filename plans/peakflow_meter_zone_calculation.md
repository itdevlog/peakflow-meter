# Схема расчета зон пикфлоуметра согласно медицинским стандартам

## 1. Введение

Система "Пикфлоуметр" использует персонализированный подход к определению зон на основе индивидуальных характеристик ребенка: возраста, пола и роста. Это позволяет более точно интерпретировать результаты измерений и своевременно выявлять изменения в состоянии здоровья.

## 2. Медицинские стандарты и формулы

### 2.1. Основные медицинские формулы для расчета нормативных значений ПСВ (пиковая скорость выдоха)

Для расчета нормативных значений используются следующие формулы:

#### Для мальчиков:
- **До 13 лет**: ПСВ = 105.4 + (5.52 × рост в см) - (0.028 × возраст²)
- **13-18 лет**: ПСВ = 79.6 + (4.25 × рост в см) + (2.18 × возраст)

#### Для девочек:
- **До 13 лет**: ПСВ = 98.3 + (4.76 × рост в см) - (0.026 × возраст²)
- **13-18 лет**: ПСВ = 69.0 + (3.35 × рост в см) + (1.95 × возраст)

### 2.2. Определение зон по процентам от нормативного значения

Система использует следующие зоны:

#### Зеленая зона (норма):
- 80-100% от нормативного значения ПСВ
- Индикатор хорошего контроля состояния

#### Желтая зона (осторожно):
- 60-79% от нормативного значения ПСВ
- Требует внимания и возможной коррекции лечения

#### Красная зона (опасность):
- Ниже 60% от нормативного значения ПСВ
- Требует немедленного медицинского вмешательства

## 4. Реализация в системе

### 4.1. Модель данных

В таблице `profile_settings` будут храниться рассчитанные границы зон:

```sql
-- Добавление полей для границ зон в profile_settings
zone_green_min INTEGER -- минимальное значение зеленой зоны (80% от нормы)
zone_yellow_min INTEGER -- минимальное значение желтой зоны (60% от нормы)
zone_red_min INTEGER -- минимальное значение красной зоны (ниже 60% от нормы)
```

### 4.2. Сервисный слой

Создается сервис `ZoneCalculator`, который:

1. Получает профиль ребенка (пол, возраст, рост)
2. Вычисляет нормативное значение ПСВ по медицинским формулам
3. Рассчитывает границы зон
4. Определяет зону для конкретного измерения

```python
class ZoneCalculator:
    def calculate_normal_pef(self, gender, age, height):
        """Рассчитывает нормативное значение ПСВ по медицинским формулам"""
        if gender == 'male':
            if age < 13:
                normal_pef = 105.4 + (5.52 * height) - (0.028 * age**2)
            else:
                normal_pef = 79.6 + (4.25 * height) + (2.18 * age)
        else:  # female
            if age < 13:
                normal_pef = 98.3 + (4.76 * height) - (0.026 * age**2)
            else:
                normal_pef = 69.0 + (3.35 * height) + (1.95 * age)
        
        return int(normal_pef)
    
    def calculate_zone_boundaries(self, normal_pef):
        """Рассчитывает границы зон на основе нормативного значения"""
        green_min = int(normal_pef * 0.8)
        yellow_min = int(normal_pef * 0.6)
        red_min = int(normal_pef * 0.6) - 1  # Для определения нижней границы
        
        return {
            'green_min': green_min,
            'yellow_min': yellow_min,
            'red_min': red_min
        }
    
    def determine_zone(self, measurement_value, normal_pef):
        """Определяет зону для конкретного измерения"""
        percentage = (measurement_value / normal_pef) * 100
        
        if percentage >= 80:
            return 'green'
        elif percentage >= 60:
            return 'yellow'
        else:
            return 'red'
```

## 5. Особенности реализации

### 5.1. Обновление нормативов

При изменении параметров ребенка (рост, возраст), система автоматически пересчитывает нормативные значения и границы зон.

### 5.2. История изменений

Система сохраняет историю изменений нормативных значений для отслеживания динамики развития ребенка.

### 5.3. Валидация входных данных

Перед расчетом система проверяет корректность входных данных:
- Возраст должен быть в диапазоне 3-18 лет
- Рост должен быть в диапазоне 90-200 см
- Пол должен быть указан корректно

## 6. Примеры расчетов

### Пример 1: Мальчик 10 лет, рост 140 см
- Норма ПСВ = 105.4 + (5.52 × 140) - (0.028 × 10²) = 105.4 + 772.8 - 2.8 = 875.4 л/мин
- Зеленая зона: ≥ 700 л/мин (80% от нормы)
- Желтая зона: 525-699 л/мин (60-79% от нормы)
- Красная зона: < 525 л/мин (ниже 60%)

### Пример 2: Девочка 15 лет, рост 160 см
- Норма ПСВ = 69.0 + (3.35 × 160) + (1.95 × 15) = 69.0 + 536 + 29.25 = 634.25 л/мин
- Зеленая зона: ≥ 507 л/мин (80% от нормы)
- Желтая зона: 380-506 л/мин (60-79% от нормы)
- Красная зона: < 380 л/мин (ниже 60%)

## 7. Медицинская валидация

Рассчитанные значения и формулы соответствуют рекомендациям Европейского респираторного общества (ERS) и Американской торакальной общества (ATS) по использованию пикфлоуметрии в педиатрической практике.
